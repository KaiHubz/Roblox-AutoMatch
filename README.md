# KaiHubz Auto Match

A Roblox Auto Match utility with a clean, compact interface.

## Features

- **Auto Match** — starts matchmaking.
- **Auto Replay** — automatically starts another match after the previous match ends.
- **Match Information** — displays available match and player details.
- **Uptime Tracker** — tracks how long the script has been running.
- **Clean UI** — draggable, minimizable, and toggleable interface.
